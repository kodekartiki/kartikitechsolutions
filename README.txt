# KartikiTechSolutions Website

A responsive, original corporate website built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — colours, responsive layout, and styling
- `script.js` — mobile menu, reveal animations, service preselection, and WhatsApp enquiry form

## Run locally
1. Extract the ZIP file.
2. Open the `KartikiTechSolutions-Website` folder.
3. Double-click `index.html` to open it in your browser.
4. For a smoother development workflow, open the folder in VS Code and use the Live Server extension.

## Publish online
You can deploy this static website with GitHub Pages, Netlify, or Cloudflare Pages. To use a custom `.com` domain, buy the domain separately and connect it in your hosting provider's domain settings. A domain purchase and DNS setup are not included in this ZIP.

## Important
The enquiry form opens WhatsApp with a prefilled message; it does not send email or store submissions on a server. Google Fonts are loaded online, so the fonts may fall back to system fonts when offline.
